# Gracetic AI — Startup Funding Predictor

AI-powered startup funding prediction application built with Python, scikit-learn, and Streamlit.

## Files

- `app.py` — Streamlit web application
- `gracetic_startup_funding_model.pkl` — trained scikit-learn pipeline
- `requirements.txt` — deployment dependencies

## Model

The model predicts `Total_Funding_USD_Millions` using startup valuation, startup age, monthly burn rate, city, domain, and country.
